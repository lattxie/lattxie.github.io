Getting Started

Install


npm install -g lattxie

Or use directly without installing:


npx lattxie@latest init my-site

Create a Project


lattxie init my-site
cd my-site

This creates:


my-site/
  pages/
    index.tex       # Your home page
    blog/
      index.tex     # /blog (uses \listpages)
      post.tex      # /blog/post
  layouts/
    default.html    # HTML template with {{title}} and {{content}}
  public/
    styles.css      # Static assets
  latty.config.json # Configuration

Run the Dev Server


lattxie dev

Open http://localhost:3000. Changes to any file in pages/ or layouts/ trigger an automatic browser reload.If port 3000 is busy, it tries 3001, 3002, etc.

Edit a Page

Open pages/index.tex and change the content. Save — the browser reloads automatically.

Build for Production


lattxie build

Output goes to _out/ — a fully static site ready to deploy.

Preview the Built Site


lattxie serve

Serves the _out/ directory locally on port 3000.

Deploy

Upload _out/ to any static host:

  • Vercel: Build command lattxie build, output _out

  • Netlify: Build command lattxie build, publish _out

  • GitHub Pages: Push _out/ to gh-pages

  • S3/Cloudflare: Sync _out/ to your bucket
