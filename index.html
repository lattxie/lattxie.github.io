What is Lattxie?

Lattxie is a static site generator that converts LaTeX files into HTML pages. Write your content in LaTeX, use the familiar file-based routing from Next.js, and deploy to any static host.


npm install -g @lattxie/lattxie   # GitHub Packages
# or
npm install -g lattxie            # npmjs.com

mkdir my-site && cd my-site
lattxie init .
lattxie dev      # http://localhost:3000
lattxie build    # outputs _out/

Why Lattxie?

  • Zero runtime dependencies — one install, that's it

  • File-based routing — pages/blog/post.tex → /blog/post

  • Pretty URLs — no .html extensions, automatically

  • Live reload — edit .tex, see changes instantly

  • Dynamic listings — \listpages{blog} auto-generates link lists

  • No JavaScript required — pure HTML output

  • Deploy anywhere — Vercel, Netlify, GitHub Pages, S3

Quick Start

  1. npx @lattxie/lattxie init my-site

  2. cd my-site && lattxie dev

  3. Edit pages/index.tex

  4. lattxie build when ready

File-Based Routing

Pages live in pages/. The file path determines the URL:

File

URL

pages/index.tex

/

pages/about.tex

/about

pages/blog/index.tex

/blog

pages/blog/post.tex

/blog/post

pages/essays/reducing-token-usage.tex

/essays/reducing-token-usage

Each page is rendered through a layout (default: layouts/default.html) which receives {{title}} and {{content}}.

Auto-Listing with \listpages

Instead of manually maintaining a list of blog posts, use:


\listpages

This scans pages/blog/, reads each .tex file's \title{}, and generates a list of links. Add a new post and it appears automatically.

Supported LaTeX

Text Formatting

\textbf{bold}, \textit{italic}, \emph{emphasis}, \underline{underline}, \texttt{mono}, \textcolor{red}{text}

Links

\href{url}{text}

Images

\includegraphics[width=0.5\textwidth]{image.jpg}

Lists

itemize, enumerate, description environments

Environments

center, verbatim, quote, quotation, abstract, figure, table, tabular

Math

$...$ for inline, $...$ for display

Metadata

\title{}, \author{}, \date{}, \layout{}

Page Commands

\section{}, \subsection{}, \subsubsection{}, \vspace{}, \bigskip, \par

Deploy

Build your site and deploy the _out/ directory.

Vercel


Build command:  lattxie build
Output dir:    _out

Netlify


Build command:  lattxie build
Publish dir:   _out

GitHub Pages

Push _out/ to gh-pages branch, or use GitHub Actions.

Configuration

latty.config.json in your project root:


{
  "title": "My Site",
  "layout": "default",
  "outputDir": "_out",
  "pagesDir": "pages",
  "layoutsDir": "layouts",
  "publicDir": "public"
}
