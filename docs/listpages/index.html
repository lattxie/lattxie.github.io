Auto-Listing with \listpages

The \listpages command automatically generates a list of links from files in a subdirectory of pages/.

Basic Usage

In your blog index page (pages/blog/index.tex):


\listpages

This scans pages/blog/ for all .tex files (except index.tex), reads each file's \title{}, and generates:


<ul>
  <li><a href="/blog/post-title">Post Title</a></li>
  <li><a href="/blog/another">Another Post</a></li>
</ul>

How It Works

  1. During lattxie build or lattxie dev, the \listpages{blog} command triggers a filesystem scan

  2. It reads pages/blog/ (excluding index.tex)

  3. Each .tex file is parsed to extract its \title{}

  4. Links are generated in alphabetical order by filename

  5. Files without \title{} use the filename (minus .tex) as the display text

Directory Index Pages

To use \listpages, you need both:

  • pages/blog/index.tex — the index page containing \listpages{blog}

  • pages/blog/post-1.tex, pages/blog/post-2.tex, etc. — the actual pages

The index page is served at /blog, each post at /blog/post-1.

Examples

Blog Index


\title
\layout

\section

\listpages

Essays Index


\title
\layout

\section

\listpages

Limitations

  • Only scans one level deep (no recursive subdirectory listing)

  • Sorts alphabetically by filename (no date-based ordering yet)

  • Only works during build/dev — it's a static filesystem scan, not a runtime database
