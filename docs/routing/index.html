Routing

Lattxie uses file-based routing, inspired by Next.js. The file path inside pages/ determines the URL.

Basics

File

URL

pages/index.tex

/

pages/about.tex

/about

pages/contact.tex

/contact

Nested Routes

Create subdirectories for nested paths:

pages/blog/index.tex

/blog

pages/blog/post.tex

/blog/post

pages/blog/hello-world.tex

/blog/hello-world

pages/essays/essay.tex

/essays/essay

Index Files

A file named index.tex in a directory becomes the root URL of that directory. For example, pages/blog/index.tex maps to /blog.

Pretty URLs

All URLs are clean — no .html extension. Lattxie automatically generates:

  • about.tex → about/index.html (in the build output)

  • blog/post.tex → blog/post/index.html

  • index.tex → index.html (stays at root)

This ensures every page is accessible at /path or /path/ without any server configuration.

404 Pages

If a page doesn't exist, Lattxie renders a styled "Not Found" page using the project's default layout — so it matches the rest of your site.
