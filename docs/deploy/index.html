Deployment

Lattxie produces a fully static _out/ directory. Deploy it to any static hosting provider.

Build


lattxie build

Output goes to _out/ (configurable via latty.config.json).

Vercel

  1. Push to GitHub

  2. Import repo on Vercel

  3. Set: 


Build command:  lattxie build
Output dir:    _out

Or with a vercel.json:


{
  "buildCommand": "npx lattxie@latest build",
  "outputDirectory": "_out"
}

Netlify

  1. Push to GitHub

  2. Import repo on Netlify

  3. Set: 


Build command:  npx lattxie@latest build
Publish dir:   _out

GitHub Pages

Option 1 — push _out/ to gh-pages branch:


lattxie build
cd _out
git init
git checkout -b gh-pages
git add . && git commit -m "deploy"
git remote add origin <repo-url>
git push -f origin gh-pages

Option 2 — use GitHub Actions to build and deploy.

Any Static Host

Upload the contents of _out/ to:

  • AWS S3 + CloudFront

  • Cloudflare Pages

  • Firebase Hosting

  • Any web server (nginx, Apache, Caddy)

Since the output is plain HTML + CSS + assets, it works everywhere.
