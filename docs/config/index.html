Configuration

Lattxie reads configuration from latty.config.json in the project root.

Default Configuration


{
  "title": "My Lattxie Site",
  "layout": "default",
  "outputDir": "_out",
  "pagesDir": "pages",
  "layoutsDir": "layouts",
  "publicDir": "public"
}

Fields

Field

Default

Description

title

"My Lattxie Site"

Fallback title for pages without \title{}

layout

"default"

Default layout name from layouts/

outputDir

"_out"

Build output directory

pagesDir

"pages"

Where .tex source files live

layoutsDir

"layouts"

Where .html templates live

publicDir

"public"

Static assets (copied as-is to output)

Example with custom paths


{
  "title": "My Blog",
  "layout": "blog",
  "outputDir": "dist",
  "pagesDir": "content",
  "layoutsDir": "templates",
  "publicDir": "static"
}
