CLI Commands

lattxie init

Scaffold a new project.


lattxie init .          # Initialize current directory
lattxie init my-site    # Create and initialize a new directory

lattxie dev

Start the development server with live reload.


lattxie dev             # Default port 3000
lattxie dev --port 4000 # Custom port

Changes to .tex, .html, .css, and .js files in pages/, layouts/, and public/ trigger automatic browser reload via SSE (Server-Sent Events).If the specified port is in use, it automatically tries the next available port (3000 → 3001 → 3002, up to +10).

lattxie build

Build the static site for production.


lattxie build

  • Cleans the _out/ directory

  • Converts every .tex in pages/ to index.html in the matching subdirectory

  • Copies public/ assets

  • Reports per-file success or errors (build continues on error)

lattxie serve

Preview the built site locally.


lattxie serve             # Default port 3000
lattxie serve --port 5000

Serves the _out/ directory with proper MIME types and directory index fallback.

lattxie help

Show the help message.

lattxie version

Print the installed version.

Installation

Install from either registry:


npm install -g lattxie            # npmjs.com
npm install -g @lattxie/lattxie   # GitHub Packages

GitHub Packages requires one-time auth:


npm login --scope=@lattxie --registry=https://npm.pkg.github.com/

CI/CD (GitHub Actions)

On every push to main, the package is auto-published to both registries:

  1. npmjs.com — uses NPM_TOKEN secret

  2. @lattxie/lattxie — uses automatic GITHUB_TOKEN

The site itself is deployed to lattxie.github.io from the lattxie/lattxie.github.io repo.
